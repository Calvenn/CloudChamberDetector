# Independent algorithm modules

Each assigned member develops only the corresponding algorithm file:

| Algorithm | File |
|---|---|
| Convolutional Neural Network | `cnn.py` |
| Neuro-Explicit Model | `neuro_explicit.py` |
| YOLOv5 | `yolov5.py` |
| Modified U-Net | `modified_unet.py` |
| Mask R-CNN Model | `mask_rcnn_model.py` |

The files and GUI pages are intentionally empty until member development
begins. Integration rules and common output contracts will be agreed before
the final comparison is implemented.
